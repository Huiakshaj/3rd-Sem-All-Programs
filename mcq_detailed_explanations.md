## MCQ 1: The value of log₂ x² = 2, then value of x is
**Answer: (a) 2**

**Reason:**
log₂ x² = 2

Using logarithm property: log_a b^n = n log_a b
2 log₂ x = 2
log₂ x = 1

If log₂ x = 1, then x = 2¹ = 2

**Why not other options?**
- (b) -2: Would give log₂(-2) which is undefined for real logarithms
- (c) ±2: Only positive value works in real logarithm domain
- (d) 4: If x = 4, then log₂(16) = 4 ≠ 2

## MCQ 3: If the roots of the equation ax² - bx + c = 0 are reciprocal to each other, then
**Answer: (c) c = a**

**Reason:**
Let the roots be α and β where β = 1/α (reciprocal)

Product of roots = α × β = α × (1/α) = 1

But from quadratic formula: Product of roots = c/a

Therefore: c/a = 1
∴ **c = a**

**Why not other options?**
- (a) a = b: No relationship between coefficient of x² and x
- (b) b = c: This would relate coefficient of x to constant term incorrectly
- (d) none of these: We have a definite answer

## MCQ 6: If i = √-1, then i²⁰²⁴ + i²⁰²⁵ + i²⁰²⁶ + i²⁰²⁷ =
**Answer: (d) 0**

**Reason:**
Powers of i cycle every 4 terms:
- i¹ = i
- i² = -1
- i³ = -i
- i⁴ = 1
- i⁵ = i (cycle repeats)

For i²⁰²⁴: 2024 = 4 × 506, so i²⁰²⁴ = (i⁴)⁵⁰⁶ = 1⁵⁰⁶ = 1
For i²⁰²⁵: 2025 = 4 × 506 + 1, so i²⁰²⁵ = i
For i²⁰²⁶: 2026 = 4 × 506 + 2, so i²⁰²⁶ = i² = -1
For i²⁰²⁷: 2027 = 4 × 506 + 3, so i²⁰²⁷ = i³ = -i

Sum = 1 + i + (-1) + (-i) = **0**

**Pattern:** Any four consecutive powers of i always sum to 0!

## MCQ 7: The fifth term in the expansion of (1 + x)⁵ is
**Answer: (a) 5x⁴**

**Reason:**
General term in binomial expansion: T_(r+1) = ⁿCᵣ × aⁿ⁻ʳ × bʳ

For (1 + x)⁵, fifth term means r+1 = 5, so r = 4

T₅ = ⁵C₄ × 1⁵⁻⁴ × x⁴ = 5 × 1 × x⁴ = **5x⁴**

**Why not other options?**
- (b) Same as (a) - correct
- (c) 10x⁴: This would be 6th term coefficient in (1+x)⁵ expansion... wait, no. 10 appears as ⁵C₂ or ⁵C₃
- (d) none of these: We have a definite answer

**Note:** ⁵C₄ = 5!/(4!×1!) = 5

## MCQ 8: The middle term of the expansion of (x² + 1/x²)⁸ is
**Answer: (a) 70**

**Reason:**
Since n = 8 (even), middle term = (8/2 + 1)th term = 5th term

T₅ = T_(4+1) = ⁸C₄ × (x²)⁸⁻⁴ × (1/x²)⁴
    = ⁸C₄ × x⁸ × (1/x⁸)
    = ⁸C₄ × 1
    = 8!/(4!×4!)
    = (8×7×6×5)/(4×3×2×1)
    = 1680/24
    = **70**

**Why not other options?**
- (b) 80: Not a binomial coefficient for n=8
- (c) 70: Same as (a) - correct
- (d) none of these: We have a definite answer

## MCQ 9: If the vectors 2î - ĵ + 5k̂ and aî - 2k̂ are perpendicular, then a =
**Answer: (c) 5**

**Reason:**
Two vectors are perpendicular if their dot product = 0

(2î - ĵ + 5k̂) · (aî + 0ĵ - 2k̂) = 0

2a + (-1)(0) + 5(-2) = 0
2a + 0 - 10 = 0
2a = 10
**a = 5**

**Why not other options?**
- (a) 2: Would give dot product = 4 - 10 = -6 ≠ 0
- (b) -5: Would give dot product = -10 - 10 = -20 ≠ 0
- (d) none of these: We have a definite answer

## MCQ 12: tan⁻¹(1/2) + tan⁻¹(1/3) =
**Answer: (c) π/4**

**Reason:**
Using the formula: tan⁻¹(a) + tan⁻¹(b) = tan⁻¹[(a+b)/(1-ab)]

tan⁻¹(1/2) + tan⁻¹(1/3) = tan⁻¹[(1/2 + 1/3)/(1 - 1/6)]
                         = tan⁻¹[(5/6)/(5/6)]
                         = tan⁻¹(1)
                         = **π/4** (since tan 45° = 1)

**Why not other options?**
- (a) π/2 = 90°: tan(π/2) is undefined
- (b) π/3 = 60°: tan(π/3) = √3 ≠ 1
- (d) none of these: We have a definite answer

## MCQ 14: If tan A = cot B, then A + B =
**Answer: (a) 90°**

**Reason:**
Given: tan A = cot B

We know: cot B = tan(90° - B)

Therefore: tan A = tan(90° - B)

This means: A = 90° - B
∴ **A + B = 90°**

**Alternative reasoning:**
tan A = cot B = 1/tan B
tan A × tan B = 1
This is the condition for A + B = 90° (complementary angles)

**Why not other options?**
- (b) 60°: No special relationship
- (c) 45°: Would require tan A = 1, not generally true
- (d) 0°: Would require A = -B

**Why not other options?**

- (d) none: We have a definite answer

## MCQ 16: If the vectors î - ĵ + k̂ and î + aĵ + k̂ are collinear, a =
**Answer: (b) -1**

**Reason:**
Two vectors are collinear if one is a scalar multiple of the other.

Let î - ĵ + k̂ = λ(î + aĵ + k̂)

Comparing coefficients:
- î: 1 = λ(1) → λ = 1
- ĵ: -1 = λ(a) → -1 = 1(a) → a = -1
- k̂: 1 = λ(1) → λ = 1 ✓

Therefore **a = -1**

**Why not other options?**
- (a) 1: Would give î - ĵ + k̂ ≠ î + ĵ + k̂
- (c) 0: Would give î + k̂, missing ĵ component
- (d) none of these: We have a definite answer

## MCQ 19: If f(x-1) = x² - x + 1, then f(x) =
**Answer: (a) x² + x + 1**

**Reason:**
Let y = x - 1, then x = y + 1

Substituting in f(x-1):
f(y) = (y+1)² - (y+1) + 1
     = y² + 2y + 1 - y - 1 + 1
     = y² + y + 1

Replacing y with x:
**f(x) = x² + x + 1**

**Verification:** If x = 2, then f(1) should equal 2² - 2 + 1 = 3
f(1) = 1² + 1 + 1 = 3 ✓

**Why not other options?**
- (b) x² - x + 1: This is f(x-1), not f(x)
- (c) x² + x - 1: Wrong constant term
- (d) none of these: We have a definite answer

## MCQ 22: The derivative of sin x w.r.t. cos x is
**Answer: (c) -cot x**

**Reason:**
We need d(sin x)/d(cos x)

Using chain rule: d(sin x)/d(cos x) = [d(sin x)/dx] / [d(cos x)/dx]

= (cos x) / (-sin x)
= -(cos x/sin x)
= **-cot x**

**Why not other options?**
- (a) tan x: Wrong sign and wrong ratio
- (b) cot x: Missing negative sign
- (d) none of these: We have a definite answer
